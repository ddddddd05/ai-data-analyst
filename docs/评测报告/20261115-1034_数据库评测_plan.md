<details><summary>S01：各品类的销售额分别是多少？</summary>

```sql
SELECT
  p.category AS 品类,
  ROUND(SUM(oi.unit_price * oi.quantity), 2) AS 销售额
FROM order_items oi
JOIN products p ON oi.product_id = p.product_id
GROUP BY p.category
ORDER BY 销售额 DESC
```

<details><summary>S04：哪个地区的客单价最高？是多少？</summary>

```sql
WITH region_stats AS (
  SELECT
    o.region AS 地区,
    ROUND(SUM(oi.unit_price * oi.quantity), 2) AS 销售额,
    COUNT(DISTINCT o.order_id) AS 订单数
  FROM orders o
  JOIN order_items oi ON oi.order_id = o.order_id
  GROUP BY o.region
)
SELECT
  地区,
  销售额,
  订单数,
  ROUND(销售额 * 1.0 / 订单数, 4) AS 客单价
FROM region_stats
ORDER BY 客单价 DESC
LIMIT 1
```

</details>

<details><summary>S05：2025 年哪个月的销售额最高？是多少？</summary>

```sql
WITH monthly_sales AS (
  SELECT
    strftime('%Y-%m', o.order_date) AS 月份,
    ROUND(SUM(oi.unit_price * oi.quantity), 2) AS 销售额
  FROM orders o
  JOIN order_items oi ON oi.order_id = o.order_id
  WHERE strftime('%Y', o.order_date) = '2025'
  GROUP BY strftime('%Y-%m', o.order_date)
)
SELECT
  月份,
  销售额
FROM monthly_sales
ORDER BY 销售额 DESC
LIMIT 1
```
