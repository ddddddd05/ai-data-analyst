<details><summary>S01：各品类的销售额分别是多少？</summary>

```sql
SELECT p.category AS 品类,
       ROUND(SUM(oi.unit_price * oi.quantity), 2) AS 销售额,
       ROUND(SUM(CASE WHEN oi.is_returned = 0 THEN oi.unit_price * oi.quantity ELSE 0 END), 2) AS 净销售额,
       SUM(oi.quantity) AS 销量,
       COUNT(DISTINCT oi.order_id) AS 订单数,
       ROUND(COUNT(DISTINCT CASE WHEN oi.is_returned = 1 THEN oi.order_id END) * 1.0 / COUNT(DISTINCT oi.order_id), 4) AS 退货率,
       ROUND(AVG(oi.rating), 2) AS 平均评分,
       COUNT(*) AS 明细行数
FROM order_items oi
JOIN products p ON oi.product_id = p.product_id
GROUP BY p.category
ORDER BY 销售额 DESC;
```
```sql
d = df.copy()

    'metrics': {'总销售额': round(float(total), 2),
                '总净销售额': round(float(d['净销售额'].sum()), 2),
                '总销量': int(d['销量'].sum())},
    'tables': {'品类销售额': d}
}
```
